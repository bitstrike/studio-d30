# Interface Wireframe

![Wireframe mockup](label-interface.png)

## Layout

Three-panel layout:

### Left Panel - Controls
- Icon (selector)
- Top Text (input)
- Bottom Text (input)
- Font (selector)
- Font Size (selector)

### Right Panel - Label Preview
- Live preview at actual label proportions
- Two-row label layout:
  - Top row: Icon (left) + Top Label Text (right)
  - Bottom row: Bottom Label Text (full width)

### Bottom Bar
- Status bar / help text / description
