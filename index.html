Connection Troubleshooting

If the printer won't connect, try these steps in order:

  1. Wake the printer - Press the D30's button. It sleeps after a few seconds of inactivity.
  2. Disconnect at OS level - If your system has an active BLE connection, the web app can't connect.
    bluetoothctl disconnect <ADDRESS>
  3. Remove and re-pair - Stale pairing data can block connections.
    bluetoothctl remove <ADDRESS>
    Then try connecting from the web app again.
  4. Restart Bluetooth service
    sudo systemctl restart bluetooth
  5. Check permissions - Your user needs to be in the bluetooth group.
    sudo usermod -aG bluetooth $USER
    Log out and back in after.
  6. Verify Chromium flags - Open chrome://flags/#enable-web-bluetooth and ensure it is enabled.
